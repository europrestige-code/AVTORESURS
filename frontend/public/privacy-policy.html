2. КАТЕГОРИИ ПЕРСОНАЛЬНЫХ ДАННЫХ

2.1. Обязательные данные для регистрации:

  • Фамилия, имя, отчество

  • Адрес доставки (полный почтовый адрес)
  • Паспортные данные (для таможенного оформления)
  • ИНН (при необходимости)
  • Информация о предпочитаемых способах оплаты

2.3. Автоматически собираемые данные:

  • IP-адрес
  • Информация о браузере и операционной системе
  • Данные о посещенных страницах и времени визитов
  • Файлы cookie и аналогичные технологии
  • Геолокационные данные (при согласии пользователя)

4. СПОСОБЫ ОБРАБОТКИ ПЕРСОНАЛЬНЫХ ДАННЫХ

4.1. Мы используем следующие способы обработки:

  • Сбор — получение данных от пользователя
  • Запись — фиксация данных на материальном носителе
  • Систематизация — упорядочивание данных в базах данных
  • Накопление — действия по сохранению данных
  • Хранение — содержание данных в информационных системах
  • Уточнение — обновление и изменение данных
  • Использование — применение данных для достижения целей обработки
  • Передача — предоставление данных третьим лицам
  • Блокирование — временное прекращение обработки
  • Удаление — уничтожение данных

4.2. Обработка осуществляется:

  • С использованием средств автоматизации (информационные системы)
  • Без использования средств автоматизации (бумажные носители)
